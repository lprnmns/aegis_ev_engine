# UX Specification

## Design personality

- Enterprise-grade.
- Calm, confident, readable.
- Evidence-first.
- No hacker aesthetic.
- No aggressive red-team language in default UI.

## Main screens

### 1. Workspace dashboard

- Recent projects.
- Retest due items.
- Risk trend.
- Last audit events.

### 2. Scope setup

- Target URL/domain.
- Authorization owner.
- Expiry date.
- Rate budget.
- Egress profile.
- Safe Mode toggle locked on by default.

### 3. Validation run

- Timeline of steps.
- Request budget used.
- Adapter status.
- Pause/stop controls.
- Approval queue.

### 4. Evidence viewer

- Raw evidence with redaction.
- Finding links.
- Timestamps.
- Tool versions.

### 5. Report builder

- Executive summary editor.
- Finding selection.
- Customer branding later.
- Export Markdown/PDF.

## UX anti-patterns

- “Attack now” buttons.
- Hidden background traffic.
- Auto-continue after block.
- Terminal-only workflows.
- Unexplained AI decisions.
