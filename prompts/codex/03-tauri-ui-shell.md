# Codex Task 03 — Tauri UI Shell

Goal: create the first Tauri + React + TypeScript shell without integrating dangerous tools.

Tasks:

1. Create `apps/desktop` using Tauri v2, React, TypeScript, and TailwindCSS.
2. Build screens:
   - Workspace dashboard,
   - Scope setup,
   - Validation run timeline,
   - Approval queue,
   - Evidence viewer,
   - Report builder placeholder.
3. Implement a mocked engine client first.
4. Add TypeScript types mirroring `docs/05_DATA_MODEL.md`.
5. Add visual states for allowed, denied, approval required, running, stopped, completed.
6. Add tests/lint if the stack supports it.
7. Do not wire arbitrary shell commands into the UI.

Deliver a UI shell that is safe, professional, and demoable.
