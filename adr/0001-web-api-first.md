# ADR 0001 — Web/API First

## Status

Accepted.

## Context

The original vision includes Web, Android, iOS, desktop binaries, WAF validation, and AI orchestration. Shipping all of this in one MVP would create unbounded scope and reduce credibility.

## Decision

Phase 1 will target only modern Web/API exposure validation.

## Consequences

- Faster path to useful MVP.
- Stronger product positioning.
- Smaller safety surface.
- Mobile and desktop modules become later product lines.
